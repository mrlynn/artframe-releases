# ArtFrameRemote releases

Downloads for **ArtFrameRemote**, the Mac app that turns a Google TV or Android TV
into a gallery of museum art and photography, with ArtFrame for TV inside it.

**Get it at [artframe.mlynn.dev](https://artframe.mlynn.dev)**, or take the newest
disk image from [Releases](https://github.com/mrlynn/artframe-releases/releases/latest).

- Requires macOS 14 Sonoma or later and a Google TV or Android TV.
- Every release is signed with a Developer ID and notarized by Apple.
- The app updates itself: it checks [the appcast](https://artframe.mlynn.dev/appcast.xml)
  and installs only updates signed with its key.

Setup help and a guide for every TV brand: [artframe.mlynn.dev/tvs](https://artframe.mlynn.dev/tvs).
